# Data Analytics Internship Project

Analysis of the UCI Online Retail dataset (541,909 transactions, Dec 2010 – Dec 2011).

## Tasks
1. **EDA & Data Cleaning**: outlier filtering, imputation, descriptive plots
2. **Customer Segmentation**: RFM analysis, cohort retention, BI-ready exports
3. **Hypothesis Testing & Forecasting**: Welch's t-test, ANOVA, Chi-Square, SARIMA 30-day forecast

See [Internship_Tasks.pdf](Internship_Tasks.pdf) for the full report and source code.

## Tools
Python, Pandas, Matplotlib, Seaborn, SciPy, Statsmodels
